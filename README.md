# 🌱 Lucknow Vegetation Change Analysis (2017–2026)

A satellite-based vegetation analysis project using **Google Earth Engine, Sentinel-2 imagery, Python, Pandas, and Matplotlib** to study changes in vegetation across Lucknow between **2017 and 2026**.

---

## 📌 Project Overview

This project analyzes satellite imagery of **Lucknow, India** to understand how vegetation has changed between 2017 and 2026.

Sentinel-2 satellite imagery was collected for both years and processed using **Google Earth Engine**. The **Normalized Difference Vegetation Index (NDVI)** was calculated to estimate vegetation levels and compare changes over time.

The project also samples satellite pixels to create a dataset that can be analyzed using Python.

---

## 🎯 Objectives

- Analyze satellite imagery of Lucknow from 2017 and 2026
- Calculate vegetation levels using NDVI
- Compare average vegetation between the two years
- Identify locations where vegetation increased or decreased
- Extract pixel-level data for further analysis
- Visualize vegetation changes using maps and statistical summaries
